원본: https://septem-nds.netlify.app/ · 모든 예시는 vendor/main.scoped.css(.nds-scope) 기준이며 레거시 소스와 분리되어 있습니다.

신규/개선 화면 시작 템플릿 (Full Page) 신규/개선 팝업 시작 템플릿 (Bottom Sheet) 전체 카탈로그 (라이브 원본 사이트) 샘플 화면 4종 (전체 컴포넌트 조합)

이 페이지 사용법

아래 컴포넌트들은 vendor/main.scoped.css에 이미 스코프 처리(.nds-scope)되어 실제로 검증된 것만 실었습니다. 각 항목의 코드 블록을 그대로 복사해서 class="nds-scope"가 걸린 영역(예: 신규 화면의 container) 안에 붙여넣으면 됩니다. 레거시 소스에 영향이 없는지는 이미 확인되었습니다. 현재 Button/Badge/Card/Accordion/Attached File/Bullet/Calendar/Check/Chip/Divider/ Empty/Indicator/Infobox/Input/Label/List/Radio/Select/Switch/Textarea/Toast/Tooltip 22종이 포함되어 있습니다. 여기 없는 것(Controls/Filter/Navigation/Popup/Process/Search/Statusbar/Table/Terms/Page title/Unit 등, 주로 페이지 골격/내비게이션류)은 아직 로컬로 추출하지 않았으니, 위 "전체 카탈로그" 링크에서 확인한 뒤 같은 방식(그레핑 → 충돌 확인 → .nds-scope 접두어)으로 vendor/main.scoped.css에 추가해서 쓰면 됩니다.
