아래 컴포넌트들은 assets/css/nds.css 에 이미 스코프 처리( .nds )되어 실제로 검증된 것만 실었습니다. 각 항목의 코드 블록을 그대로 복사해서 class="nds" 가 걸린 영역(예: 신규 화면의 container) 안에 붙여넣으면 됩니다. 레거시 소스에 영향이 없는지는 이미 확인되었습니다. 클래스 네이밍 규칙 (BEM)

이 가이드의 모든 클래스는 표준 BEM(Block__Element--Modifier) 표기법을 따릅니다.
블록(Block) : 컴포넌트 이름. 여러 단어면 바( - ) 하나로 구분합니다. 예: accordion-gray (= accordion + gray)
엘리먼트(Element) : 블록 안의 하위 요소. 블록과는 언더바 두 개( __ )로 구분합니다. 예: accordion-gray__item
엘리먼트 이름 자체가 여러 단어면 그 안에서도 바( - )로 구분합니다. 예: accordion-gray__row-icons (= row + icons라는 엘리먼트)
모디파이어(Modifier) : 상태/변형. 바 두 개( -- )로 구분합니다. 예: accordion-gray--open , btn--primary
즉 언더바( __ )는 블록↔엘리먼트 경계에만 쓰이고, 바( - / -- )는 이름 내부 단어 구분(한 개)과 모디파이어 표시(두 개)에 쓰입니다. 새 컴포넌트를 추가할 때도 이 규칙을 그대로 따라주세요.

Radius (Figma 원본 대조 완료)

모든 컴포넌트의 테두리 모양과 반경(Radius)을 통일하여 인터페이스의 시각적 일관성을 유지합니다. 특정 모양을 사용해 사용자 시선을 끌어 인터페이스의 핵심 요소에 주의를 집중하도록 합니다. 기준에 따른 모양을 적용하여 사용자가 상호작용할 수 있는 요소를 쉽게 식별할 수 있도록 돕습니다.

Spacing (Figma 원본 대조 완료)

인터페이스 요소와 화면 가장자리 간의 공간을 정의하여 전체 레이아웃의 균형과 일관성을 유지하는 역할을 합니다. 요소 간 간격을 규칙적으로 설정하여 사용자에게 시각적 안정감을 제공합니다. 고정값 또는 화면 너비에 비례하는 값을 사용함으로써 다양한 디바이스 해상도에서 최적의 사용자 경험을 제공할 수 있도록 합니다. 8px(8-Point grid)의 배수를 사용하여 인터페이스 요소 간의 일관성과 조화를 유지해야 합니다. 4px의 배수 간격은 필요에 따라 적용하며, 세밀한 조정을 통해 다양한 콘텐츠 요구와 상황에 유연하게 대응합니다.
