상속세 입력

  • 상속세 정보 입력
    • 피상속인의 거주자여부
    • 피상속인의 배우자여부
    • 배우자를 제외한(생존 중인) 상속인
      0
    • 피상속인보다 먼저 사망한 상속인
      (대습상속인 경우)
      0
    • 선순위 상속권자의 상속포기로
      후순위 상속권자의 상속 여부
    • 유증으로 상속받는 손자/손녀 여부
    • 유증으로 상속받는 기타가족 여부
    • 공익/종교단체에 유증
      기부한 상속 재산 여부

  • 증여재산 정보입력

    부담부증여일 경우 채무인수액을 차감한 금액을 입력합니다. 가업승계에 대한 증여특례는 자녀인 상속인 한 명에게 증여할 때만 가능합니다. 수증자가 여러명이 될 수 없습니다.

    • 상속인에게 10년 이내에 증여 여부
      • 배우자 증여여부
      • 증여한 직계존속/비속(부모/자녀)
        0
      • 증여한 대습상속인
        0
      • 증여한 대승상속인 가업승계 증여특례여부
    • 상속인외의 자에게 5년 이내에 증여 여부
      • 증여한 직계비속(손자/손녀)
        0
      • 증여한 직계존속(부모)
        0
      • 증여한 기타친족/무관계인
        0

  • 상속재산가액 입력

    동일한 상속재산에 대해서 영농·영어상속공제와 가업상속공제는 동시에 적용할 수 없습니다.

      • 상속재산1
      • 상속재산의 종류
        아파트/빌라/단독주택
      • 배정내역(분할)

        상속재산을 누구에게 배정했는지를 표시합니다. 법정상속지분과 다르게 지분으로 상속재산을 분할할 경우 상속인지 각자 평가금액을 입력하십시오.

        법정지분 상속
      • 상속재산 평가금액
        (약 1억 346만원)
        원 입력내용삭제
      • 동거가족 상속공제
      • 영농 · 영어 상속공제
      • 중소기업 가업상속공제 여부
    • 상속재산 추가
    • 피상속인 경영기간
      10년 미만

  • 공제내역 입력

    채무, 공과금 등은 법정상속지분으로 상속인에게 승계하는 것으로 가정합니다.

    • 피상속인의 금융채무액
      (약 1억 346만원)
      원 입력내용삭제
    • 피상속인의 일반채무액
      (일반채무, 임차인의 보증금)
      (약 1억 346만원)
      원 입력내용삭제
    • 피상속인의 납부예정 공과금(세금포함)
      (약 1억 346만원)
      원 입력내용삭제
    • 봉인시설 자연장지에 지출한 금액
      (약 1억 346만원)
      원 입력내용삭제
    • 그 외 증빙가능한 장례비 지출액
      (약 1억 346만원)
      원 입력내용삭제

  • 감정평가비용 입력
    • 부동산
      (약 1억 346만원)
      원 입력내용삭제
    • 비상장주식
      (약 1억 346만원)
      원 입력내용삭제
    • 서화, 골동품 등 유형재산
      (약 1억 346만원)
      원 입력내용삭제
