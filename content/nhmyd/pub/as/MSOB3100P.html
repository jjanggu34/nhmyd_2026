  • 해외여행 어디로 가세요?
  • 인원은 몇 명인가요?
    명 입력내용삭제
    +1명 +2명 +3명 +4명 +5명

    인원은 최대 30명까지 입력 가능합니다.

  • 얼마나 머무르실 건가요?

    여행 기간은 1일=당일, 2일=1박2일로 입력해 주세요.

    일 입력내용삭제
    +1일 +3일 +5일 +7일 +10일

    기간은 최대 60일까지 입력 가능합니다.

  • 해외여행 스타일은 어떤 타입인가요?
  • 여유자금은 얼마인가요?
    만원 입력내용삭제
    +1만 +10만 +30만 +50만 +100만 +300만

    1부터 9,999,999만원까지 입력 가능합니다.

  • 필요 여행경비

    여행경비 계산식은 아래와 같습니다.
    { [ ( 평균 경비 + 여행 스타일 비용 ) * 기간 ] + 여유자금 } * 인원 수

    0만원
    • 필요 여행경비는 항공료를 제외한 1일 평균 경비를 토대로 계산한 비용입니다.
